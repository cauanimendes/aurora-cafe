# ☕ Aurora Café

Landing page minimalista e responsiva desenvolvida como projeto conceitual para o portfólio da **Nexo Digital**.

## ✨ Sobre o projeto

O Aurora Café é uma landing page fictícia de cafeteria, criada com foco em elegância, simplicidade e experiência do usuário.

O projeto apresenta uma identidade visual acolhedora, navegação intuitiva e adaptação para diferentes tamanhos de tela.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- GitHub
- Cloudflare Pages
